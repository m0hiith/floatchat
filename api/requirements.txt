# The API's dependencies, and only the API's.
#
# `requirements.txt` at the repo root is the full freeze: it builds the
# database, and it carries netCDF4, xarray and pandas to do it.  Installed,
# that tree is 301 MB against a serverless function's ~250 MB uncompressed
# budget, so a deployment that reuses it does not fit.  This closure is 127 MB
# and does (D15.9).
#
# It is a SUBSET, not a second opinion.  Every line below appears verbatim in
# the root freeze at the same version, because two freezes that can disagree
# eventually will -- and rule 6 pins exactly for the same reason.  The
# transitive closure is listed rather than left to the resolver.
#
# Dropped, all of them ETL-only: cftime, netCDF4, pandas, python-dateutil, six, xarray
#
# `uvicorn` is NOT dropped, though the function never starts a server: the
# `__main__` block of api/server.py imports it, and a freeze that omits an
# import its own source makes is a freeze that is wrong about the source.  It
# costs about 1.5 MB.  The first draft of this file dropped it and
# api/test_deploy.py caught that, which is the entire argument for the check.
#
# Regenerate by walking installed metadata from the direct set
# {fastapi, psycopg, psycopg-binary, numpy, faiss-cpu, anthropic, google-genai, uvicorn}; api/test_deploy.py re-proves the closure every run.
